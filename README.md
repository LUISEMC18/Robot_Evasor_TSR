# Robot Evasor de Obstáculos — FI UNAM

Proyecto de robótica desarrollado en la clase **ROBÓTS MÓVILES** enfocado en la navegación autónoma y evasión de obstáculos mediante sensores y microcontroladores.

---

### 🛠️ Tecnologías y Hardware
- **Lenguajes / Entornos:** C++ / Arduino 
- **Componentes:** Motores  Pololu 3081, Sensores infrarrojos, Chasis 2 ruedas circular, Puente H L298N, Arduino Uno
